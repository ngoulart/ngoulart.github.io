Lei dos Grandes Números

À medida que o tamanho da amostra n cresce, a média amostral Ȳₙ converge em probabilidade para a média populacional μ. Os intervalos abaixo mostram o quantil 2.5%–97.5% de R repetições para cada n — note como a faixa colapsa em torno de μ.

Ȳn = (1/n) Σᵢ Yᵢ  ⟶p  μ  quando  n → ∞

sample_sizes <- c(10, 50, 100, 500, 1000, 10000)
n_reps       <- 500
results      <- data.frame()

for (n in sample_sizes) {
  mu_reps <- replicate(n_reps, mean(rlnorm(n, 0, 1)))
  results <- rbind(results, data.frame(
    n     = n,
    lower = quantile(mu_reps, 0.025),
    upper = quantile(mu_reps, 0.975),
    mean  = mean(mu_reps)
  ))
}

ggplot(results, aes(x = n)) +
  geom_ribbon(aes(ymin = lower, ymax = upper), alpha = 0.5) +
  geom_hline(yintercept = exp(0.5), linetype = "dotted") +
  scale_x_log10()
