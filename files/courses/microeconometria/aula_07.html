Regressão Descontínua: Identificação Local

Quando o tratamento é uma função descontínua de uma variável running R em torno de um corte c, podemos identificar o efeito causal localmente comparando indivíduos imediatamente abaixo e acima do corte. O design exige continuidade dos potenciais E[Y(d)|R = r] em r = c — qualquer descontinuidade na densidade de R ao redor do corte (manipulação) invalida o desenho.

A população desta página difere do workbook: bolsa de mestrado com corte em R = 700 de uma prova padronizada. Quem tem R ≥ 700 recebe a bolsa (D = 1); o desfecho Y é o tempo até a defesa (em meses, menor é melhor — então o efeito esperado é negativo).

1
O salto em Y no corte

O scatter binado com ajuste polinomial local mostra a evolução de Y ao longo de R. O tamanho do salto em R = c é τ̂SRD. O ajuste é feito separadamente à esquerda e à direita do corte.

R
# RDD com pacote rdrobust
library(rdrobust)

est <- rdrobust(y = data$Y, x = data$R,
                c = 700, p = 1)
summary(est)

# Plot binado oficial
rdplot(y = data$Y, x = data$R,
       c = 700, p = 1,
       binselect = "esmv")

Sensibilidade à bandwidth

O estimador local depende de h. Bandwidths grandes reduzem a variância mas aumentam o viés (uso de pontos longe do corte); bandwidths pequenas fazem o oposto. Use o slider para variar h e observe estabilidade. rdrobust::rdbwselect escolhe h ótimo via MSE.

R
# Bandwidth ótimo (Imbens-Kalyanaraman/CCT)
bw <- rdbwselect(y = data$Y, x = data$R,
                 c = 700, bwselect = "mserd")
bw$bws

# Sensibilidade
hs <- seq(10, 120, by = 10)
res <- sapply(hs, function(h) {
  rdrobust(data$Y, data$R, c = 700, h = h)$Estimate[1]
})
plot(hs, res, type = "l")

Teste de densidade (McCrary)

Sem manipulação, a densidade de R deve ser contínua em c. Se candidatos manipulam o resultado para ficar acima do corte (ou abaixo), aparece um "salto" na densidade. Use o seletor acima para ativar manipulação e veja a densidade mudar de forma.

R
# McCrary via pacote rddensity
library(rddensity)

dens <- rddensity(X = data$R, c = 700)
summary(dens)

# Plot oficial
rdplotdensity(rdd = dens, X = data$R)

Placebo: covariável pré-tratamento

Uma variável fixada antes do tratamento (ex.: idade) não pode ser afetada pelo programa. Aplicar RDD à idade no mesmo corte deve dar zero. Salto significativo é sinal de descontinuidade espúria — o desenho perde credibilidade.

R
# Placebo: aplicar RDD em covariável pré-tratamento
plac <- rdrobust(y = data$idade,
                 x = data$R,
                 c = 700, p = 1)
summary(plac)

Bateria de placebos
covars <- c("idade", "renda_familiar", "genero")

placebos <- lapply(covars, function(v) {
  fit <- rdrobust(df[[v]], df$R, c = cutoff)
  c(coef = fit$Estimate[1],
    p    = fit$pv[3])    # robust p-value
})
do.call(rbind, placebos)
