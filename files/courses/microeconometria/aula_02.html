Aula 02

Causalidade e Resultados Potenciais

Toda inferência causal começa por reconhecer que cada indivíduo carrega dois resultados potenciais — Yi(0) e Yi(1) — mas observamos apenas um. Esse é o problema fundamental: os efeitos de tratamento individuais nunca são diretamente visíveis. As médias, no entanto, podem ser. O que esta aula explora é quando elas podem ser interpretadas causalmente.

Para evitar que os gráficos "respondam" ao enunciado, a população sintética desta página é diferente da do workbook. Imagine um curso intensivo de inglês para profissionais de tecnologia, com Y = pontuação numa prova de proficiência (escala ~0–100). Cada indivíduo tem uma aptidão linguística latente U que afeta tanto o resultado base quanto o ganho com o curso — e também a probabilidade de se inscrever. Isso gera seleção tanto em níveis quanto em ganhos: ATT > ATE > ATU.

Cada painel mostra o código R à esquerda e a simulação interativa à direita. Toda computação roda no seu navegador. A seed padrão é a data de hoje (formato YYYYMMDD).

1
Resultados potenciais e o problema fundamental

Aqui vemos o que normalmente é invisível: Y(0) e Y(1) lado a lado. O primeiro gráfico compara as duas distribuições potenciais. O segundo mostra a distribuição dos efeitos individuais τi = Yi(1) − Yi(0): como τi varia entre indivíduos, há heterogeneidade de efeitos. O ATE = E[τi] é a média dessa distribuição.

R
# Resultado observado para cada indivíduo
data$Y_obs <- data$D * data$Y1 +
              (1 - data$D) * data$Y0

# Efeito individual e ATE
data$tau <- data$Y1 - data$Y0
ATE      <- mean(data$tau)

# Equivalente: diferença das médias dos POs
mu_Y0 <- mean(data$Y0)
mu_Y1 <- mean(data$Y1)
stopifnot(all.equal(ATE, mu_Y1 - mu_Y0))

Viés de seleção

Na vida real só observamos Yi(Di), e Di não é aleatório. A comparação ingênua E[Y|D=1] − E[Y|D=0] mistura o efeito do tratamento com diferenças pré-existentes nos resultados base. O gráfico abaixo mostra as quatro médias condicionais E[Y(d)|D=d'] — duas observadas (sólidas) e duas contrafactuais (hachuradas). A barra vermelha vertical na esquerda é o viés de seleção: E[Y(0)|D=1] − E[Y(0)|D=0].

R
# Diferença ingênua observada
naive <- mean(data$Y_obs[data$D == 1]) -
         mean(data$Y_obs[data$D == 0])

# Decomposição: naive = ATT + viés_seleção
ATT     <- mean(data$tau[data$D == 1])
sel_bias <- mean(data$Y0[data$D == 1]) -
            mean(data$Y0[data$D == 0])
stopifnot(all.equal(naive, ATT + sel_bias))

3
ATE, ATT e ATU

Existem três efeitos médios distintos, e eles só coincidem quando o efeito é homogêneo OU o tratamento é independente do efeito. Aqui ATT > ATE > ATU porque os indivíduos que se inscrevem (D=1) têm U mais alto e ganham mais com o tratamento (τi cresce com U). Isto é seleção em ganhos.

R
ATE <- mean(data$tau)
ATT <- mean(data$tau[data$D == 1])
ATU <- mean(data$tau[data$D == 0])

# Lei das esperanças iteradas:
# ATE = π·ATT + (1−π)·ATU,   π = P(D=1)
pi  <- mean(data$D)
stopifnot(all.equal(ATE,
            pi * ATT + (1 - pi) * ATU))

Seleção vs aleatorização (Monte Carlo)

Para cada repetição, sorteamos uma amostra de tamanho n da população e estimamos τ̂ via OLS de Y em D. Sob seleção (D original), o estimador converge para a diferença ingênua — é viesado. Sob aleatorização (D re-sorteado Bernoulli(0.5)), o estimador converge para o ATE — é não-viesado.

R
n_reps <- 1000
n      <- 1000
tau_sel <- numeric(n_reps)
tau_rct <- numeric(n_reps)

for(i in 1:n_reps) {
  s <- data[sample(nrow(data), n), ]
  tau_sel[i] <- coef(lm(Y_obs ~ D, s))[2]

  s$D_RCT <- rbinom(n, 1, 0.5)
  s$Y_RCT <- s$D_RCT*s$Y1 + (1-s$D_RCT)*s$Y0
  tau_rct[i] <- coef(lm(Y_RCT ~ D_RCT, s))[2]
}

Efeito Mínimo Detectável (MDE)

Para um experimento aleatorizado com α=0.05 bilateral e poder 1−κ=0.80: MDE = (z1−α/2 + z1−κ) · SE(τ̂RCT) ≈ 2.802 · σ̂Y·√(2/n) sob alocação 50/50. O gráfico mostra MDE em função de n — comparado ao ATE verdadeiro. Onde a curva passa abaixo do ATE, o experimento tem poder para detectá-lo.

R
z_a <- 1.96; z_k <- 0.842

# SE(τ̂_RCT) ≈ σ_Y · √(2/n) sob 50/50
sigma_Y <- sd(data$Y_obs)
mde <- function(n) {
  (z_a + z_k) * sigma_Y * sqrt(2/n)
}

ns  <- c(50, 100, 500, 1000, 5000)
data.frame(n = ns, MDE = sapply(ns, mde))

DGP com resultados potenciais
set.seed(1)
n  <- 2000

# Y(0), Y(1) latentes
Y0 <- rnorm(n, mean = 100, sd = 10)
tau <- rnorm(n, mean = 5, sd = 2)
Y1 <- Y0 + tau

# Atribuição (selection on Y0)
D <- as.integer(Y0 > quantile(Y0, .5))

# Apenas observamos Y
Y <- D * Y1 + (1 - D) * Y0
df <- data.frame(Y, D, Y0, Y1)
ATE / ATT / ATU "oráculo"
# Quando se conhece Y0 e Y1 (simulação)
ATE <- mean(df$Y1 - df$Y0)
ATT <- mean((df$Y1 - df$Y0)[df$D == 1])
ATU <- mean((df$Y1 - df$Y0)[df$D == 0])

# Diferença simples (viesada se há seleção)
naive <- mean(df$Y[df$D == 1]) -
         mean(df$Y[df$D == 0])

c(ATE = ATE, ATT = ATT,
  ATU = ATU, naive = naive)

set.seed(42)
n <- 2000

# Atribuição aleatória 50/50

Y  <- Y0 + 5 * D + rnorm(n, 0, 2)

# Estimador simples (sem viés)

MDE (Minimum Detectable Effect)
# MDE para teste two-sided 5%, poder 80%
# MDE ≈ (z_{1-α/2} + z_{1-β}) · SE(τ̂)
mde <- function(n, sigma, p = 0.5,
                alpha = .05, power = .80) {
  se <- sigma * sqrt(1/(p*(1-p)*n))
  (qnorm(1-alpha/2) + qnorm(power)) * se
}

# MDE como função de n
ns <- seq(100, 5000, by = 100)
plot(ns, mde(ns, sigma = 10),
     type = "l", xlab = "n", ylab = "MDE")
