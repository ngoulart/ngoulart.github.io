Efeitos Fixos: Absorvendo Heterogeneidade

Quando o tratamento é correlacionado com características não observadas mas fixas dentro de uma unidade, OLS pooled é viesado. Efeitos fixos removem qualquer correlação com variáveis tempo-invariantes ao centralizar cada observação em torno da média da sua unidade. O preço: usamos só variação within.

A população desta página difere do workbook: programa de mentoria em filiais de uma empresa. Cada filial tem cultura organizacional latente αg que afeta tanto a produtividade quanto a fração de funcionários sorteados (a gerência escolhe o tamanho do programa por filial). Dentro da filial, o sorteio é aleatório.

1
Pooled OLS é viesado

Filiais com cultura forte (alto αg) também tendem a participar mais do programa. Comparar tratados vs controles entre filiais mistura efeito da mentoria com diferença de cultura. O viés de OLS = Cov(D, α) / Var(D).

R
# OLS pooled: ignora a filial
fit_ols <- lm(Y ~ D, data = data)
coeftest(fit_ols, vcov = vcovHC(fit_ols, "HC1"))

# Versus efeitos fixos
library(fixest)
fit_fe <- feols(Y ~ D | filial, data = data,
                cluster = ~filial)
summary(fit_fe)

Transformação within

Demean por filial: Ỹig = Yig − ȳg e D̃ig = Dig − D̄g. A regressão de Ỹ em D̃ dá o mesmo coeficiente que feols(Y ~ D | filial) — esse é o teorema FWL.

R
# Demean manualmente (FWL)
data <- data %>%
  group_by(filial) %>%
  mutate(Y_tilde = Y - mean(Y),
         D_tilde = D - mean(D)) %>%
  ungroup()

fit_within <- lm(Y_tilde ~ D_tilde - 1, data = data)
coef(fit_within)   # = coef(fit_fe)

feols na prática

O fixest absorve FEs sem precisar criar dummies. Suporta múltiplos níveis, cluster SE, e funciona com milhões de obs. O painel compara: pooled OLS, within manual, feols, e o τ verdadeiro.

R
library(fixest)

# 1 nível de FE
m1 <- feols(Y ~ D | filial, data = data,
            cluster = ~filial)

# Múltiplos FEs (filial + região)
m2 <- feols(Y ~ D | filial + regiao,
            data = data, cluster = ~filial)

# Tabela publicável (LaTeX)
etable(m1, m2, fitstat = ~ n + r2 + ar2,
       tex = TRUE, file = "fe.tex")

Heterogeneidade por filial

Estimar τ̂g em cada filial e plotar contra a fração de tratados mostra heterogeneidade — ou ausência dela. Um padrão sistemático sugere que o efeito do programa depende de característica não observada da filial (ex.: cultura pró-mentoria).

R
# τ̂ por filial
data %>%
  group_by(filial) %>%
  filter(any(D == 1) & any(D == 0)) %>%
  summarise(tau_g       = mean(Y[D==1]) - mean(Y[D==0]),
            share_trt   = mean(D),
            n           = n()) -> tau_filial

ggplot(tau_filial,
       aes(x = share_trt, y = tau_g)) +
  geom_point() + geom_smooth(method = "lm")

Gráfico de coeficientes por grupo
library(broom); library(ggplot2)

tau_unit <- df %>%
  group_by(unit) %>%
  do(tidy(lm(Y ~ D, data = .))) %>%
  filter(term == "D")

p <- ggplot(tau_unit,
            aes(x = reorder(unit, estimate),
                y = estimate)) +
  geom_pointrange(
    aes(ymin = estimate - 1.96*std.error,
        ymax = estimate + 1.96*std.error)) +
  geom_hline(yintercept = 0, linetype = "dashed")

ggsave("figs/tau_por_unit.pdf", p,
       width = 6, height = 4)
