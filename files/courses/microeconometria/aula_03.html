Experimentos Aleatorizados: Individual vs Cluster

Em um RCT, a aleatorização garante E[Y(0)|D=1] = E[Y(0)|D=0]: comparar tratados e controles recupera o ATE. Mas como sorteamos importa. Quando o tratamento é atribuído por cluster (escolas, hospitais, municípios), observações dentro do mesmo grupo são correlacionadas — e ignorar isso na inferência infla a taxa de rejeição do teste sob H0: τ = 0.

A população desta página difere do workbook: imagine uma intervenção de nudge digital em clínicas de atenção primária, com Y = pressão arterial sistólica (mmHg) dos pacientes. Cada clínica tem um efeito latente (qualidade do atendimento) que cria correlação intraclasse. Mantemos a hipótese nula nítida (Y(1) = Y(0)) para que toda rejeição seja erro tipo I.

1
Correlação intraclasse (ICC)

Pacientes na mesma clínica compartilham um efeito latente γg. Decompondo Yig = μ + γg + εig, a ICC é ρ = σ²γ / (σ²γ + σ²ε). O gráfico esquerdo mostra a média por clínica; o direito mostra o histograma agregado: a variância between e a variância within coexistem.

R
# Modelo de variância: Y = μ + γ_g + ε
library(dplyr)

mod <- data %>%
  group_by(clinic) %>%
  summarise(ybar = mean(Y), n = n())

var_between <- var(mod$ybar)
var_within  <- mean(
  (data$Y - mod$ybar[match(data$clinic, mod$clinic)])^2
)

icc_hat <- var_between /
           (var_between + var_within)

Aleatorização individual: a referência válida

Sorteamos Di ~ Bernoulli(0.5) independente por paciente. Como τ = 0, a distribuição de τ̂ deve estar centrada em zero e o teste em α = 0.05 deve rejeitar exatamente 5% das vezes. Aqui o vcovHC é apropriado — não há clustering na atribuição.

R
# Aleatorização individual
library(sandwich); library(lmtest)

mc_individual <- function(reps = 1000) {
  rej <- numeric(reps); est <- numeric(reps)
  for (b in 1:reps) {
    D <- rbinom(nrow(data), 1, 0.5)
    fit <- lm(Y ~ D, data = data)
    ct  <- coeftest(fit, vcov = vcovHC(fit, "HC1"))
    est[b] <- ct["D", 1]
    rej[b] <- ct["D", 4] < 0.05
  }
  list(mean_est = mean(est),
       sd_est   = sd(est),
       size     = mean(rej))
}

Aleatorização por cluster: o que vcovHC esconde

Agora sorteamos Dg ~ Bernoulli(0.5) por clínica e propagamos para todos os pacientes. A distribuição verdadeira de τ̂ fica mais larga (efeitos de clínica entram em bloco). Comparamos três SEs: HC1 (incorreto, ignora clusters), CR1 cluster (correto), e o SD entre simulações (referência verdadeira).

R
# Aleatorização por cluster
library(sandwich); library(lmtest)

mc_cluster <- function(reps = 1000) {
  G  <- length(unique(data$clinic))
  ids <- sort(unique(data$clinic))
  est <- numeric(reps)
  rej_HC <- numeric(reps); rej_CL <- numeric(reps)
  for (b in 1:reps) {
    Dg <- rbinom(G, 1, 0.5)
    data$D <- Dg[match(data$clinic, ids)]
    fit <- lm(Y ~ D, data = data)
    seHC <- vcovHC(fit, "HC1")
    seCL <- vcovCL(fit, cluster = data$clinic)
    est[b]   <- coef(fit)["D"]
    rej_HC[b] <- coeftest(fit, vcov = seHC)["D", 4] < 0.05
    rej_CL[b] <- coeftest(fit, vcov = seCL)["D", 4] < 0.05
  }
  list(sd_true = sd(est),
       size_HC = mean(rej_HC),
       size_CL = mean(rej_CL))
}

Efeito Mínimo Detectável

Com α = 0.05, poder 1 − κ = 0.80: MDE = (z1−α/2 + z1−κ) · SD(τ̂). O design effect sob clustering é DE = 1 + (n̄ − 1)·ρ: ele multiplica a variância do estimador. Um RCT por cluster com mesma N tem MDE muito maior.

R
# MDE individual vs cluster (mesmo N)

MDE_clu <- (z_a + z_p) * sd_clu

DE_hat  <- (sd_clu / sd_ind)^2
