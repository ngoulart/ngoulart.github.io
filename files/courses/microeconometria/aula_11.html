DiD com Tratamento Escalonado

Quando unidades são tratadas em momentos diferentes e o efeito é heterogêneo, TWFE deixa de identificar o ATT médio. O problema: unidades já tratadas funcionam como controle para unidades recém-tratadas, gerando comparações proibidas. Estimadores como Callaway-Sant'Anna (2021) e Sun-Abraham (2021) corrigem isso comparando cada coorte só contra nunca-tratados ou ainda-não-tratados.

DGP desta página: adoção de telemedicina por hospitais. N hospitais observados em 8 anos (2016–2023). Coortes adotam em 2018, 2020, 2022, e o grupo never-treated. Efeito dinâmico cresce no tempo e diminui em coortes tardias (adoptantes precoces ganham mais por aprendizado acumulado).

Estrutura de adoção escalonada

Coortes definidas pelo ano de adoção g ∈ {2018, 2020, 2022, ∞}. O heatmap mostra cada hospital (linha) em cada ano (coluna) — branco se ainda não tratado, colorido após adoção. Coortes mais escuras = adopção mais cedo.

R
# Variável "first treatment year" (G)
# 2018, 2020, 2022, ou Inf (never)
df <- df %>%
  group_by(hospital) %>%
  mutate(G = if (any(D == 1))
                min(t[D == 1])
              else Inf) %>%
  ungroup()

Trajetórias médias por coorte

Plotar Ȳg,t ao longo do tempo, uma linha por coorte. Pré-tratamento todas devem ser paralelas. Pós-tratamento, cada coorte parte em momento diferente — note que coortes precoces eventualmente atingem efeitos maiores (parâmetro dinâmica).

R
library(dplyr); library(ggplot2)

df %>%
  group_by(G, t) %>%
  summarise(Y = mean(Y), .groups = "drop") %>%
  mutate(coorte = ifelse(is.infinite(G),
                         "never",
                         as.character(G))) %>%
  ggplot(aes(t, Y, color = coorte)) +

TWFE vs Callaway-Sant'Anna

Compara TWFE estático (uma única dummy D), ATT médio calculado só com never-treated como controle (estilo CS), e o ATT verdadeiro ponderado igualmente entre tratados pós-adoção. Aumente heterogeneidade de coorte e veja TWFE divergir.

R
library(did)

cs <- att_gt(
  yname  = "Y",
  tname  = "t",
  idname = "hospital",
  gname  = "G",         # cohort = first-treat
  data   = df,
  control_group = "nevertreated"
)

# ATT médio simples
aggte(cs, type = "simple")

# Por evento (event study)

Event study honesto (CS dinâmico)

Para cada k = t − G, calcular ATT(k) como média (entre coortes) das diferenças (Ȳg,g+k − Ȳg,g−1) − (Ȳ∞,g+k − Ȳ∞,g−1). A linha vermelha é o τ verdadeiro agregado nessa mesma forma. Pontos pré-evento próximos a zero = pré-tendências sob controle.

R
# Sun-Abraham via fixest
library(fixest)

es_sa <- feols(
  Y ~ sunab(G, t) | hospital + t,
  data    = df,
  cluster = ~hospital
)

iplot(es_sa,
      xlab = "Anos desde adoção",
      main = "Event study (Sun-Abraham)")

# Resumo agregado por k
summary(es_sa, agg = "att")

Callaway-Sant'Anna (did package)
library(did)

cs <- att_gt(
  yname    = "Y",
  tname    = "t",
  idname   = "unit",
  gname    = "G",
  data     = df,
  control_group = "nevertreated",
  # ou "notyettreated" se não há nunca-tratados
  est_method    = "reg"
)

# ATT global, dinâmico, por coorte
aggte(cs, type = "simple")
aggte(cs, type = "dynamic")
aggte(cs, type = "group")

ggdid(aggte(cs, type = "dynamic"))
Sun-Abraham (fixest)
library(fixest)

# sunab(cohort, time) gera todas as interações
es <- feols(

# Plot pronto
iplot(es)

# Agregar para ATT por k
