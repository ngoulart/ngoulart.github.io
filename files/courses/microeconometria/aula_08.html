Dados em Painel e Erros Padrão

Em painel, observações da mesma unidade ao longo do tempo são correlacionadas. Tratar cada linha como independente (OLS clássico ou HC1) subestima SE, infla t e quebra o nível do teste. A solução padrão é cluster-robust ao nível de atribuição (ou superior). Quando há choques comuns ao tempo, two-way clustering (unidade + tempo) é apropriado.

A população desta página difere do workbook: rede de farmácias com 200 lojas observadas mensalmente em 24 meses. Algumas lojas adotam um programa de fidelidade. Cada loja tem efeito fixo αi; choques mensais δt atingem todas; resíduos são AR(1) dentro de cada loja.

Variação between vs within

Decompondo Yit = ȳi + (Yit − ȳi): a primeira parte é between (ICC alta = lojas muito diferentes); a segunda é within. Estimadores de FE usam só a variação within. O painel mostra as duas distribuições.

Cobertura empírica de IC sob H0: τ = 0

Sob a hipótese nula, um IC 95% deveria cobrir 0 em 95% das simulações. O painel compara cobertura de quatro métodos: vcov clássico, HC1, CL1 (cluster por loja) e CL1 (cluster por mês).

R
# Comparar cobertura via Monte Carlo
library(sandwich); library(lmtest)

simula <- function(reps = 500) {
  cobre <- matrix(0, reps, 4)
  for (b in seq_len(reps)) {
    data$D <- bloco_aleatorio(data$loja)
    fit <- lm(Y ~ D, data = data)
    se_v <- list(
      vcov(fit),
      vcovHC(fit, "HC1"),
      vcovCL(fit, cluster = data$loja),
      vcovCL(fit, cluster = data$mes))
    for (k in 1:4) {
      ic <- coeftest(fit, vcov = se_v[[k]])["D", 1:2]
      cobre[b, k] <- abs(ic[1] / ic[2]) < 1.96
    }
  }
  colMeans(cobre)
}

Choques comuns: por que cluster por tempo

Quando um choque mensal afeta todas as lojas (ex.: feriado, política monetária), há correlação entre lojas dentro do mesmo mês. Cluster por loja sozinho não captura. Comparamos com two-way clustering (loja × tempo).

R
# Two-way clustering
library(fixest)

fit <- feols(Y ~ D | loja + mes,
             data = data,
             cluster = ~loja + mes)
summary(fit)

# Equivalente em sandwich:
seCL2 <- vcovCL(lm(Y ~ D + factor(loja) + factor(mes),
                   data = data),
                cluster = ~ loja + mes)

ICC empírico
icc_emp <- function(df, unit_col, y_col) {
  bw <- df %>%
    group_by(.data[[unit_col]]) %>%
    summarise(ybar = mean(.data[[y_col]]),
              n    = n())

  vb <- var(bw$ybar)
  vw <- mean((df[[y_col]] -
              bw$ybar[match(df[[unit_col]],
                            bw[[unit_col]])])^2)
  vb / (vb + vw)
}
Pairs bootstrap por cluster
boot_cluster <- function(df, B = 1000) {
  units <- unique(df$unit)
  taus  <- numeric(B)
  for (b in seq_len(B)) {
    pick <- sample(units, length(units),
                   replace = TRUE)
    bs   <- bind_rows(lapply(pick,
              function(u) df[df$unit == u, ]))
    taus[b] <- coef(lm(Y ~ D, bs))["D"]
  }
  c(media = mean(taus), sd = sd(taus),
    q025 = quantile(taus, 0.025),
    q975 = quantile(taus, 0.975))
}
