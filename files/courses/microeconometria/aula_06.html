Variáveis Instrumentais e LATE

Quando o tratamento D é endógeno e X não é suficiente para a CIA, precisamos de um instrumento Z que satisfaça três requisitos: relevância (Cov(Z, D) ≠ 0), exogeneidade ({Y(0), Y(1)} ⊥ Z), e exclusão (Z só afeta Y via D). Sob monotonicidade, o estimador IV identifica o LATE — o efeito médio sobre os compliers.

A população desta página difere do workbook: loteria de subsídio para motoristas de aplicativo (Brasília). Z = ofereceu subsídio (sorteio aleatório); D = aderiu ao subsídio (decisão do motorista); Y = faturamento mensal (R$). Sob monotonicidade, a oferta nunca desincentiva a adesão.

1
Por que OLS é viesado

Cada motorista tem uma habilidade latente U que aumenta tanto Y(0) quanto a probabilidade de aderir voluntariamente. Comparar E[Y|D=1] e E[Y|D=0] mistura seleção (quem adere tem mais habilidade) com efeito causal (o subsídio aumenta o faturamento).

R
# OLS ingênuo
fit_ols <- lm(Y ~ D, data = data)
coeftest(fit_ols, vcov = vcovHC(fit_ols, "HC1"))

# Mostra viés contra ATE verdadeiro
ATE <- mean(data$Y1 - data$Y0)
c(OLS = coef(fit_ols)["D"], ATE = ATE)

2
First stage: o instrumento move D?

FS = E[D|Z=1] − E[D|Z=0]. Se for próximo de zero, o instrumento é fraco e os erros padrão de IV explodem (regra prática: F > 10). Os compliers são aqueles com D(1)=1, D(0)=0: a fração de compliers é exatamente a magnitude do first stage.

R
# First stage
fit_fs <- lm(D ~ Z, data = data)
fs_coef <- coef(fit_fs)["Z"]

# Estatística F (regra: F > 10)
F_fs <- summary(fit_fs)$fstatistic[1]

c(first_stage = fs_coef, F = F_fs)

3
Forma reduzida: Z sobre Y

RF = E[Y|Z=1] − E[Y|Z=0]. Sob aleatorização do instrumento, esse é o efeito causal de oferecer o subsídio (intent-to-treat). Não é o efeito do subsídio em si — porque nem todos a quem foi oferecido aderiram.

R
# Forma reduzida (= ITT do instrumento)
fit_rf <- lm(Y ~ Z, data = data)
rf_coef <- coef(fit_rf)["Z"]

# Mesma coisa, mas em uma chamada IV
library(AER)
fit_iv <- ivreg(Y ~ D | Z, data = data)
summary(fit_iv,
        vcov = vcovHC(fit_iv, "HC1"),
        diagnostics = TRUE)

Wald = RF / FS = LATE

τ̂Wald = (E[Y|Z=1] − E[Y|Z=0]) / (E[D|Z=1] − E[D|Z=0]). Sob exogeneidade, exclusão e monotonicidade, τ̂Wald →p E[Y(1) − Y(0) | complier]. O painel compara OLS, RF, Wald e o ATE/LATE verdadeiros.

R
# Wald estimador (cálculo direto)
yz1 <- mean(data$Y[data$Z == 1])
yz0 <- mean(data$Y[data$Z == 0])
dz1 <- mean(data$D[data$Z == 1])
dz0 <- mean(data$D[data$Z == 0])

tau_wald <- (yz1 - yz0) / (dz1 - dz0)
c(Wald = tau_wald)

# Equivalente
ivreg(Y ~ D | Z, data = data)$coef["D"]

Caracterizando os compliers
# Tamanho do grupo de compliers
share_compliers <- mean(df$D[df$Z == 1]) -
                   mean(df$D[df$Z == 0])

# Médias de X por tipo (Abadie kappa weighting)
df$kappa <- 1 - df$D*(1-df$Z) /
                (1 - mean(df$Z)) -
            (1-df$D)*df$Z / mean(df$Z)

# Média de X entre compliers
sum(df$X * df$kappa) / sum(df$kappa)
