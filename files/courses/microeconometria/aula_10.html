Diferença em Diferenças (DiD)

DiD identifica o efeito do tratamento sob tendências paralelas: na ausência do tratamento, tratados e controles teriam evoluído de forma idêntica. Comparar as variações entre os grupos cancela diferenças fixas (níveis) e choques comuns (tendência).

DGP desta página: piloto de jornada 4×3 (semana de 4 dias) em empresas de tecnologia. N=150 empresas observadas em T=8 trimestres (2022Q1–2023Q4). 60 empresas adotaram a política em 2023Q1 (período t=5). Outcome: receita por funcionário (R$ mil/trimestre). Você pode ligar uma violação de tendência paralela e ver o estimador colapsar.

1
Séries temporais por grupo

A primeira diagnóstico: plotar a média do outcome ao longo do tempo, separadamente para tratados e controles. Antes de t=5, as duas séries devem caminhar em paralelo. Depois, a tratada salta. Aumente β nos controles globais para introduzir tendência diferencial e veja o paralelismo quebrar.

R
# Médias por (grupo, t)
library(dplyr); library(ggplot2)

df %>%
  group_by(treated, t) %>%
  summarise(Y = mean(Y), .groups = "drop") %>%
  ggplot(aes(x = t, y = Y,
             color = factor(treated))) +
  geom_line() + geom_point() +
  geom_vline(xintercept = 4.5,
             linetype = "dashed") +
  labs(color = "tratado")

Estimador 2×2

Colapsando para 2 períodos (pré vs pós), o estimador DiD é τ̂ = (ȲT,pos − ȲT,pre) − (ȲC,pos − ȲC,pre). A primeira diferença remove o efeito fixo da empresa; a segunda diferença remove o choque comum no tempo.

R
tab <- df %>%
  mutate(post = t >= 5) %>%
  group_by(treated, post) %>%
  summarise(Y = mean(Y), .groups = "drop")

# 2x2
xtabs(Y ~ treated + post, data = tab)

# DiD via lm com interação
lm(Y ~ treated * post, data = df)

TWFE com fixest

Com painel completo (T > 2), a forma canônica é Two-Way Fixed Effects: Yit = αi + δt + τ·Dit + εit. Com tratamento simultâneo e efeito homogêneo, TWFE = 2×2. A barra mostra: 2×2, TWFE, e τ verdadeiro.

R
library(fixest)

# TWFE com SE clusterizado por empresa
fit_twfe <- feols(
  Y ~ D | empresa + t,
  data    = df,
  cluster = ~empresa
)
summary(fit_twfe)

# Equivalente quando tratamento é simultâneo
feols(Y ~ treated:post | empresa + t,
      data = df, cluster = ~empresa)

Event study

Substituir Dit por dummies relativas ao evento (k = t − t0), omitindo k = −1 como categoria base. Os leads testam pré-tendências (devem ser próximos de zero); os lags traçam a dinâmica do efeito. Bandas: IC 95%.

R
# Event time relativo ao tratamento
df <- df %>%
  mutate(event = ifelse(treated == 1, t - 5, NA))

# Estimação com referência em k=-1
fit_es <- feols(
  Y ~ i(event, ref = -1) | empresa + t,
  data    = df,
  cluster = ~empresa
)

# Plot pronto
iplot(fit_es,
      xlab = "Trimestres desde o tratamento",
      main = "Event study DiD")

Permutation/placebo test
# Sortear "tratamento" aleatório B vezes,
# ver onde τ̂ verdadeiro cai na distribuição
B <- 1000
ids <- unique(df$empresa)
nT  <- sum(df$treated[!duplicated(df$empresa)])

placebo <- replicate(B, {
  fake <- sample(ids, nT)
  df$D_p <- as.integer(df$empresa %in% fake &
                       df$t >= 5)
  coef(feols(Y ~ D_p | empresa + t, df))["D_p"]
})

mean(abs(placebo) >= abs(coef(fit_twfe)["D"]))
