Atrito Diferencial e Bounds de Lee

Mesmo em RCTs perfeitos, o ATE é ameaçado quando não observamos o outcome para parte dos indivíduos. Se a probabilidade de responder depende do tratamento (atrito diferencial) e/ou do potencial outcome, a média condicional ao subgrupo observado deixa de identificar o ATE. Bounds de Lee tornam essa ignorância parcial em um intervalo identificado sob hipóteses fracas (monotonicidade).

A população desta página difere do workbook: imagine uma plataforma de cursos online com sorteio de acesso a um tutor de IA. Y é a nota final na avaliação; S = 1 indica que o aluno completou o curso (e, portanto, observamos Y). Tipos com maior aptidão tendem a completar mais; o tratamento aumenta a conclusão dos tipos marginais — então a média condicional muda de composição.

1
O mecanismo de atrito

Cada aluno tem aptidão latente U. Y(0) e Y(1) crescem com U. A probabilidade de completar é P(S=1|D,U) = Φ(γ0 + γD·D + γU·U): o tratamento aumenta a conclusão e atrai os tipos marginais. O gráfico mostra P(S=1|D) ao longo de U.

Diagnósticos: quantidade e composição

Dois testes essenciais:
(i) Quantidade. A taxa de atrito é igual entre tratados e controles? Teste de proporções para S em função de D.
(ii) Composição. Quem ficou em cada braço se parece em variáveis pré-tratamento X? Regressão de X em D restrita a S=1.

R
# (i) Diferença na taxa de atrito
prop.test(table(data$D, data$S))

# (ii) Composição dos respondentes
obs <- data %>% filter(S == 1)

fit_X <- lm(X ~ D, data = obs)
coeftest(fit_X, vcov = vcovHC(fit_X, "HC1"))

4
Bounds de Lee (2009)

Sob monotonicidade (o tratamento só aumenta a probabilidade de responder), podemos identificar bounds para o ATT na subpopulação always-takers: remover do braço com maior taxa de resposta uma fração q = (P(S=1|D=1) − P(S=1|D=0)) / P(S=1|D=1) dos respondentes — pelos extremos da distribuição — gera o upper e lower bound.

R
# Lee bounds — passo a passo
p1 <- mean(data$S[data$D == 1])
p0 <- mean(data$S[data$D == 0])
q  <- (p1 - p0) / p1   # fração a aparar

obs <- data %>% filter(S == 1)
y1  <- obs$Y[obs$D == 1]; y0 <- obs$Y[obs$D == 0]

# Trim do braço com mais respondentes (D=1)
qL <- quantile(y1, q);  qU <- quantile(y1, 1 - q)

upper <- mean(y1[y1 >= qU]) - mean(y0)
lower <- mean(y1[y1 <= qL]) - mean(y0)
c(lower = lower, upper = upper)

Lee bounds em uma função
lee_bounds <- function(df) {
  p1 <- mean(df$S[df$D == 1])
  p0 <- mean(df$S[df$D == 0])
  trim_high <- p1 > p0
  q <- abs(p1 - p0) / max(p1, p0)

  obs <- df[df$S == 1, ]
  y_t <- if (trim_high) obs$Y[obs$D == 1] else obs$Y[obs$D == 0]
  y_o <- if (trim_high) obs$Y[obs$D == 0] else obs$Y[obs$D == 1]

  qL <- quantile(y_t, q); qU <- quantile(y_t, 1 - q)
  hi <- mean(y_t[y_t >= qU])
  lo <- mean(y_t[y_t <= qL])
  delta <- if (trim_high) c(lo, hi) - mean(y_o) else mean(y_o) - c(hi, lo)
  c(lower = min(delta), upper = max(delta))
}

# H0: composição preservada após atrito
library(sandwich); library(lmtest)

obs <- subset(df, S == 1)

vars <- c("X1", "X2", "baseline_y")
res  <- lapply(vars, function(v) {
  f <- as.formula(paste(v, "~ D"))
  fit <- lm(f, data = obs)
  c(diff = coef(fit)[2],
    p    = coeftest(fit, vcovHC(fit, "HC1"))[2, 4])
