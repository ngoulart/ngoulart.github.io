Aula 05

Seleção em Observáveis (CIA)

Quando o tratamento não é aleatório, mas a seleção depende somente de covariáveis observáveis X, vale a hipótese de independência condicional: {Y(0), Y(1)} ⊥ D | X. Sob CIA, podemos identificar o ATE comparando tratados e controles dentro de cada valor de X e tirando uma média ponderada. A regressão multivariada faz isso, mas com pesos próprios que nem sempre coincidem com o ATE.

A população desta página difere do workbook: bolsa de iniciação científica para graduandos, com X ∈ {básico, intermediário, avançado, expert} (faixa pré-tratamento de desempenho) e Y = produtividade científica medida 12 meses depois. Quem tem maior X tem maior chance de receber a bolsa e maior Y(0).

Propensity por estrato

Cada faixa X tem sua própria P(D=1|X) — o propensity score. Suporte comum: precisamos ter tratados e controles em cada estrato (caso contrário, certos contrafactuais não existem).

Naive vs CIA: balanço dentro de cada X

A diferença simples ȲD=1 − ȲD=0 é viesada porque compara estratos diferentes. Mas dentro de cada X, E[Y|X,D=1] − E[Y|X,D=0] identifica o ATE condicional. O gráfico mostra E[Y|X,D] por estrato — as barras devem ter diferenças semelhantes ao verdadeiro τ(x).

R
# Diferença ingênua
naive <- mean(data$Y[data$D == 1]) -
         mean(data$Y[data$D == 0])

# Diferença dentro de cada X
data %>%
  group_by(X, D) %>%
  summarise(media_Y = mean(Y),
            n       = n()) %>%
  pivot_wider(names_from = D,
              values_from = c(media_Y, n)) %>%
  mutate(tau_x = media_Y_1 - media_Y_0)

3
Matching exato: ATE e ATT

Sob CIA: τ̂ATE = Σx π(x) · τ̂(x), onde π(x) = P(X=x) (frequência marginal).
Para o ATT, ponderamos pelos tratados: τ̂ATT = Σx π(x|D=1) · τ̂(x). Quando τ(x) varia com x, ATE ≠ ATT.

R
# Matching exato — passo a passo
strat <- data %>%
  group_by(X) %>%
  summarise(tau_x  = mean(Y[D==1]) - mean(Y[D==0]),
            pi_x   = n() / nrow(data),
            piTr_x = sum(D) / sum(data$D))

ATE_hat <- sum(strat$tau_x * strat$pi_x)
ATT_hat <- sum(strat$tau_x * strat$piTr_x)

c(ATE = ATE_hat, ATT = ATT_hat)

Pesos da regressão multivariada

A regressão Y = α + τ·D + Σ βx·1{X=x} + u também produz uma média ponderada dos τ(x), mas com pesos ω(x) ∝ π(x) · p(x)·(1 − p(x)): a regressão dá mais peso a estratos onde a variância de D é maior (p(x) ≈ 0.5) e menos peso a estratos com propensity extrema. Sob heterogeneidade, τ̂OLS ≠ ATE.

R
# Regressão saturada com efeitos fixos de X
fit <- lm(Y ~ D + factor(X), data = data)
tau_OLS <- coef(fit)["D"]

# Pesos implícitos da regressão
strat <- strat %>%
  mutate(p_x   = pi_x,
         varD  = ((sum(data$D)/nrow(data)) -    # aprox.
                  mean(D[X == X])) ,            # pseudo
         omega = pi_x * (P_D1*(1-P_D1)),
         omega = omega / sum(omega))

Pesos implícitos da OLS
# Decomposição de Angrist (1998) / Aronow-Samii
omega_x <- df %>%
  group_by(X) %>%
  summarise(p_x  = n() / nrow(df),
            phat = mean(D)) %>%
  mutate(w_unnorm = p_x * phat * (1 - phat),
         omega_OLS = w_unnorm / sum(w_unnorm))

# Comparar com pesos do ATE (π(x))
omega_x %>% select(X, p_x, omega_OLS)
Estimar tau(x) e agregar
tau_x <- df %>%
  group_by(X) %>%
  summarise(tau   = mean(Y[D==1]) - mean(Y[D==0]),
            n_t   = sum(D),
            n_c   = sum(1-D),
            n     = n())

ATE <- sum(tau_x$tau * tau_x$n)         / sum(tau_x$n)
ATT <- sum(tau_x$tau * tau_x$n_t)       / sum(tau_x$n_t)
ATU <- sum(tau_x$tau * tau_x$n_c)       / sum(tau_x$n_c)
c(ATE, ATT, ATU)
