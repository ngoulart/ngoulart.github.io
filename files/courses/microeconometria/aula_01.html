Aula 01

Revisão de Probabilidade: Simulação e Inferência Estatística

Antes de qualquer técnica de inferência causal, é fundamental separar três conceitos distintos: parâmetro populacional (um valor fixo e desconhecido na população, como μY), estimador (uma fórmula aplicada a uma amostra, como Ȳ = (1/n)Σ Yi) e estimativa (o número concreto que sai da fórmula numa amostra específica). Os cinco painéis abaixo constroem essa distinção visualmente, mostrando como o comportamento de Ȳ muda conforme cresce o tamanho da amostra.

Para que a visualização não "responda" diretamente a sua lista, a população sintética desta página é diferente da do enunciado: N=100.000 indivíduos, com Y = horas mensais de leitura (mistura bimodal: leitores leves N(5, 2²) e leitores ávidos N(25, 5²)) e tratamento binário D = ensino superior completo. Use a página para construir intuição — depois reproduza o pipeline na base data_01.RData da disciplina.

Cada painel mostra o código R à esquerda e a simulação interativa à direita. Toda computação roda no seu navegador, então sinta-se à vontade para mexer nos sliders e re-rodar. A seed padrão é a data de hoje (formato YYYYMMDD), de modo que cada visita à página produz uma nova realização da população.

1
Parâmetros populacionais

Como D é binário, o coeficiente τ da regressão de Y em D tem leitura simples: é exatamente a diferença de médias condicionais E[Y|D=1] − E[Y|D=0] — equivalente a comparar o grupo com ensino superior completo ao grupo sem. O primeiro gráfico mostra a distribuição de Y com μY (linha vermelha) e a faixa μ ± σY. O segundo gráfico mostra Y vs D, com os pontos vermelhos em E[Y|D=0] e E[Y|D=1]: a inclinação da reta entre eles é τ.

R
# Três parâmetros populacionais
mu_Y    <- mean(data$leitura)
sigma_Y <- sd(data$leitura)

# Como D é binário, τ é exatamente
# a diferença de médias condicionais:
tau <- coef(lm(leitura ~ superior,
              data = data))[2]
# equivalente a:
m1  <- mean(data$leitura[data$superior == 1])
m0  <- mean(data$leitura[data$superior == 0])
stopifnot(all.equal(tau, m1 - m0))

ci     <- mu_hat + c(-1.96, 1.96) * se_hat

Simulação de Monte Carlo

Repita o sorteio R vezes (default 1000), guardando cada Ȳ. Compare a média e o desvio-padrão da distribuição amostral com os valores teóricos μY e σY/√n, e meça a cobertura empírica do IC 95%.

R
n_sims  <- 1000
n       <- 100
mu_hats <- numeric(n_sims)
covers  <- logical(n_sims)

for(i in 1:n_sims) {
  s <- data[sample(nrow(data), n), ]
  mu_hats[i] <- mean(s$leitura)
  se   <- sd(s$leitura) / sqrt(n)
  ci   <- mu_hats[i] + c(-1.96, 1.96) * se
  covers[i] <- ci[1] <= mu_Y & ci[2] >= mu_Y
}

Lei dos Grandes Números

Para tamanhos amostrais n ∈ {10, 50, 100, 500, 1000, 10000}, simule 1000 estimativas de Ȳ e plote o intervalo entre os quantis 2,5% e 97,5%. A faixa colapsa em torno de μY — convergência em probabilidade.

R
sizes <- c(10, 50, 100, 500, 1000, 10000)
n_reps <- 1000

res <- do.call(rbind, lapply(sizes, function(n) {
  m <- replicate(n_reps,
         mean(data$leitura[sample(nrow(data), n)]))
  data.frame(n  = n,
             lo = quantile(m, 0.025),
             hi = quantile(m, 0.975))
}))

ggplot(res, aes(x = n)) +
  geom_ribbon(aes(ymin = lo, ymax = hi)) +
  scale_x_log10()

Teorema Central do Limite

Padronize Z = (Ȳ − μY) / (σY/√n) e plote a densidade de Z para diferentes n. Mesmo partindo de uma população bimodal (dois grupos de leitores), a distribuição converge para a normal padrão.

R
sizes  <- c(10, 100, 1000)
n_reps <- 1000

z_df <- do.call(rbind, lapply(sizes, function(n) {
  z <- replicate(n_reps, {
    s <- data$leitura[sample(nrow(data), n)]
    (mean(s) - mu_Y) / (sd(s) / sqrt(n))
  })
  data.frame(n = n, z = z)
}))

ggplot(z_df, aes(z, color = factor(n))) +
  geom_density() +
  stat_function(fun = dnorm)
