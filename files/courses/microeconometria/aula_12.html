Controle Sintético (SCM)

Quando há uma unidade tratada e muitos potenciais controles, SCM (Abadie-Gardeazabal-Hainmueller) constrói um contrafactual como combinação convexa do donor pool. Os pesos wj ≥ 0, Σwj = 1 são escolhidos para que o sintético reproduza o comportamento da tratada no período pré.

DGP desta página: Ceará e o programa Tablet por Aluno, lançado em 2020. Estado tratado = Ceará; doadores = 19 estados sintéticos brasileiros. T = 24 trimestres (2018Q1–2023Q4); intervenção em t = 12. Outcome: nota média do IDEB. Você controla a magnitude e a curvatura do efeito real.

1
Pré-tratamento: tratado vs sintético

O sintético é o ajuste convexo dos doadores que minimiza Σt<t0 (Y1t − Σj wj Yjt)². Antes da intervenção, sintético deve colar no tratado. Depois, divergir = efeito.

R
library(Synth)

dp <- dataprep(
  foo            = df,
  predictors     = c("X1", "X2"),
  dependent      = "Y",
  unit.variable  = "unit_id",
  time.variable  = "t",
  treatment.identifier = 1,
  controls.identifier  = 2:20,
  time.predictors.prior = 1:11,
  time.optimize.ssr     = 1:11,
  time.plot             = 1:24
)
sc <- synth(dp)

Gap pós-tratamento

Plot de Y1t − Σwj Yjt. Antes do tratamento deve oscilar em torno de zero (qualidade do pré-fit). Depois, é a estimativa do ATT trajetória τ̂t.

R
# Gap = tratado − sintético
gap <- dp$Y1plot - dp$Y0plot %*% sc$solution.w

# Plot

Placebos in-space

Inferência por permutação: rodar SCM tratando cada doador como se ele tivesse sido o tratado. Se o gap do tratado verdadeiro for atípico em magnitude (ratio de RMSPE pós/pré), evidência contra o nulo. Linha colorida = tratado real; cinza = placebos.

R
# Para cada doador, refazer SCM como se
# ele fosse o tratado, plotar todos os gaps
placebo_gaps <- lapply(2:20, function(j) {
  dpj <- dataprep(...,
    treatment.identifier = j,
    controls.identifier  = setdiff(1:20, j))
  sc_j <- synth(dpj)
  dpj$Y1plot - dpj$Y0plot %*% sc_j$solution.w
})

Placebos in-space + RMSPE
# Roda SCM com cada doador como "tratado"
ids   <- 1:20
gaps  <- list()
for (j in ids) {
  dpj <- dataprep(...args com treat=j...)
  sc_j <- synth(dpj)
  gaps[[j]] <- dpj$Y1plot -
               dpj$Y0plot %*% sc_j$solution.w
}

# RMSPE ratio (pós / pré)
rmspe <- function(g, idx) sqrt(mean(g[idx]^2))
ratios <- sapply(gaps, function(g)
  rmspe(g, 12:24) / rmspe(g, 1:11))
sort(ratios, decreasing = TRUE)

library(tidysynth)

sc <- df %>%
  synthetic_control(outcome  = Y,
                    unit     = state,
                    time     = year,
                    i_unit   = "Ceará",

                    generate_placebos = TRUE) %>%
  generate_predictor(time_window = 2018:2019,
                     X1 = mean(X1)) %>%

  generate_control()
